## 🧭 About

```yaml
role:      Forward Deployed Product Manager
operates:  in the field — on-site with customers, close to the code
bridges:   engineering  ⇄  business  ⇄  the human actually using the thing
ships:     0 → 1 products, enterprise deployments, AI-native workflows
strength:  turning ambiguous, high-stakes problems into shipped outcomes
```

- 🛰️ **Forward deployed** — I don't manage product from a distance. I sit with the users, feel the pain, and close the loop fast.
- 🧩 **Full-stack PM** — discovery, strategy, specs, delivery, and the uncomfortable trade-offs in between.
- 🤖 **AI-native** — I build with LLMs in the workflow, not bolted on as an afterthought.
- 🤝 **Translator** — I turn "the customer is frustrated" into a roadmap engineering can actually build.
